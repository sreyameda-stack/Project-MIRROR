PROJECT MIRROR - STREAMLIT COMMUNITY CLOUD DEPLOYMENT

Files:
- src/MIRROR_template_ready.py : Streamlit app entrypoint
- src/MIRROR_Template.xlsx    : downloadable Excel template used by the app
- requirements.txt            : Python dependencies for cloud deployment

DEPLOY:
1. Extract this folder.
2. Create a GitHub repository and upload the contents of this folder (not the ZIP itself).
3. Visit https://share.streamlit.io/ and sign in with GitHub.
4. Click Create app.
5. Select your repository and branch (usually main).
6. Set Main file path to: src/MIRROR_template_ready.py
7. Optionally set a custom app URL, then click Deploy.

Keep src/MIRROR_Template.xlsx in the same folder as the app file. Do not rename it.
Do not upload real customer data, passwords, API keys, or private credentials to GitHub.
